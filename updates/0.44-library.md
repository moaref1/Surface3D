# Surface3D 0.44 — Asset library update

The Windows build has been prepared and checked locally. Its ZIP is not uploaded to GitHub yet; this page is a change record, not a download announcement.

- Eleven labeled icon categories: Materials, HDRIs, Models, Generators, Smart Masks, Effects, Textures, Brushes, Alphas & Stencils, Decals and Graphs.
- Poly Haven browsing opens directly within Materials, HDRIs and Models. No separate Poly Haven type selector. Cards have a PH source badge.
- Saved local materials and online materials are accessible in the same category.
- Generators and mesh-map-dependent Smart Masks are grouped separately.
- Effect icons in the layer stack, Add Effect menu and filter thumbnails.
- Double-click a project texture under Alphas & Stencils to enable it as the brush stencil.

Five targeted application/library regression checks passed. This update does not add a new local model database or change the renderer. Online browsing needs network access.

Application source remains private. The existing draft release has no binary attached; the download is not live yet.
